# MediaPipe 姿态坐姿提醒 Demo

基于谷歌开源 MediaPipe 的端侧实时坐姿分析 Demo，对应创新提案中的「姿态坐姿提醒」模块。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `posture_reminder_demo.py` | 主程序：摄像头采集 → 姿态关键点检测 → 规则判断 → 骨架可视化与坐姿统计 |
| `models/pose_landmarker.task` | 姿态识别模型（脚本首次运行缺失时会自动下载） |

## 环境要求

- Python 3.10 ~ 3.12
- 依赖安装：

```bash
pip install mediapipe opencv-python numpy
```

> 无显示的服务器装 `opencv-python-headless`；本地笔记本有摄像头和窗口界面时装 `opencv-python`。

## 运行方式

```bash
# 默认调用本机摄像头
python posture_reminder_demo.py

# 或传入视频文件做离线演示/调试
python posture_reminder_demo.py demo.mp4
```

- 画面为镜像视角，叠加人体骨架。
- 顶部显示当前状态、问题项与坐姿良好率；底部显示关键指标。
- 按 `q` 或 `Esc` 退出，结束后终端输出总帧数与良好率汇总。

## 判断规则

基于 Pose 33 关键点中的鼻、双肩、双髋位置做规则判断：

| 问题 | 判断依据 | 可调阈值 |
| --- | --- | --- |
| 身体歪斜 | 左右肩高度差过大 | `SHOULDER_TILT_MAX` |
| 含胸/前倾 | 肩中点到髋中点的躯干相对竖直方向倾角过大 | `TRUNK_ANGLE_MAX` |
| 头部前倾/低头 | 鼻尖相对肩中点左右偏移过大，或鼻尖下沉到肩线以下过多 | `HEAD_FORWARD_X` / `HEAD_DROP_Y` |

判断结果经过 `SMOOTH_FRAMES` 帧滑动多数表决，避免单帧抖动误报。

## 可调参数

- `MIN_POSE_CONFIDENCE`：关键点可见性阈值，低于则不参与判断。
- 各角度/偏移阈值：按个人坐姿基准与摄像头角度校准。
- `SMOOTH_FRAMES`：平滑窗口大小，越大越稳定但响应越慢。

## 已验证情况

- 云主机环境：模型加载与推理链路通过；直立、低头、歪斜三类规则单测正确。
- 云主机无摄像头，实时画面需在本地电脑运行。
- 规则阈值为经验默认值，正式演示前请在正常坐姿下校准基线。

## 后续可扩展
