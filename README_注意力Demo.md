# MediaPipe 人脸注意力分析 Demo

基于谷歌开源 MediaPipe 的端侧实时头部朝向分析 Demo，对应创新提案中的「人脸与注意力分析」模块。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `attention_analysis_demo.py` | 主程序：摄像头采集 → 人脸检测 → 头部姿态解算 → 朝向判断与注意力统计 |
| `models/face_landmarker.task` | 人脸网格模型（脚本首次运行缺失时会自动下载） |

## 环境要求

- Python 3.10 ~ 3.12
- 依赖安装：

```bash
pip install mediapipe opencv-python numpy
```

> 无显示的服务器装 `opencv-python-headless`；本地笔记本有摄像头和窗口界面时装 `opencv-python`。

## 运行方式

```bash
# 默认调用本机摄像头
python attention_analysis_demo.py

# 或传入视频文件做离线演示/调试
python attention_analysis_demo.py demo.mp4
```

- 顶部显示当前状态、偏离原因、人数、专注率与偏离次数。
- 底部显示俯仰 / 偏航 / 翻滚角度。
- 按 `q` 或 `Esc` 退出，结束后终端输出汇总。

## 判断规则

模型输出头部 4×4 变换矩阵，解算为三个欧拉角后与阈值比较：

| 指标 | 含义 | 阈值参数 | 超出判为 |
| --- | --- | --- | --- |
| 偏航 yaw | 左右转头 | `YAW_THRESHOLD` | 左右转头 |
| 俯仰 pitch | 抬头 / 低头 | `PITCH_THRESHOLD` | 抬头/低头 |
| 翻滚 roll | 左右歪头 | `ROLL_THRESHOLD` | 歪头 |

三项均在阈值内判为「面向屏幕」，否则判为「未面向屏幕」。结果经 `SMOOTH_FRAMES` 帧滑动多数表决防抖。

## 隐私边界（重要）

- 全程端侧本地推理，**不上传、不保存**摄像头原始画面。
- 只输出朝向状态与统计指标，**不做人脸身份识别、不做情绪识别**。
- 注意力结果仅作为参与度参考，不作为绩效考核依据。
- 若后续进入真实办公/会议场景，需明确告知采集用途并提供关闭开关。

## 可调参数

- 三个角度阈值：按屏幕距离与座位角度校准。
- `num_faces`：同时检测的人脸数量。
- `SMOOTH_FRAMES`：平滑窗口大小。

## 已验证情况

- 云主机环境：模型加载、矩阵解算与朝向判断单测通过；正面与转头 30° 判定正确。
- 云主机无摄像头，实时画面需在本地电脑运行。
